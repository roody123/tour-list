## 📌 О проекте
Веб-сайт, построенный на React. Позволяет пользователям изучать популярные туристические города, просматривать галереи фотографий и управлять списком желаемых поездок.

## 📁 Структура проекта

* `App.js` - главный компонент, управляет общим состоянием списка городов и логикой удаления.
* `CityCard.js` - дочерний компонент, отвечающий за логику отдельной карточки.
* `data.js` - модуль с данными (названия, описания и массивы ссылок на изображения).

## 🌟 Основные функции
* **Динамический список:** Отображение массива городов с помощью метода `.map()`.
* **Отдельные слайдеры:** В каждой карточке реализован собственный стейт для переключения фотографий.
* **Удобное описание:** Функция «Читать далее», которая обрезает длинные тексты с помощью `substring`.
* **Управление списком:** Возможность удалять отдельные карточки или полностью очищать список одним нажатием.

## ⚙️ Использование и запуск
Вы можете свободно использовать код этого проекта в своих целях - для обучения, модификации или как основу для своих идей.

**Запуск проекта:**

1. Склонируйте репозиторий:
```
git clone https://github.com/roody123/dodo-pizza.git
```

2. Установите зависимости:
```
npm install
```

3. Запустите проект:
```
npm run dev
```
